Lumo Studio: разделение на вашем Windows-ПК

1. Установите Python 3.11 (64-bit) с https://www.python.org/downloads/release/python-3119/
2. Распакуйте архив в отдельную папку. Запустите Install.cmd. Скачивание PyTorch занимает несколько гигабайт.
3. Запустите Start.cmd. Первое разделение дополнительно скачивает модель Demucs.
4. В Lumo Studio откройте «Подключения». Адрес ПК: http://127.0.0.1:7865. Вставьте ключ из окна Start.cmd в поле «Ключ ПК». Не отправляйте ключ в чат.
5. Загрузите песню, нажмите «Разделить», выберите Demucs 6 дорожек и «Начать разделение».
6. Разрешите браузеру доступ к локальной сети, если он запросит. Используйте Chrome/Edge на этом же ПК. С телефона этот локальный адрес не работает.

Модель htdemucs_6s: vocals, drums, bass, other, guitar, piano. Гитара и пианино экспериментальные. Модель не выделяет каждый возможный инструмент (саксофон, скрипка и т. п. останутся в other). WAV до 150 МБ; одна задача за раз. Результаты до следующей задачи лежат в jobs. Сохраните нужные дорожки до следующего разделения.

Сервер слушает только 127.0.0.1, не открывает ПК в интернете. Ключ генерируется при первом запуске. Не публикуйте access-key.txt. Аудио отправляется с сайта на ваш ПК; платных API нет. ПК должен оставаться включённым. Подключение к локальной сети может блокироваться настройками браузера.

Модель на вашем ПК ещё не проверена. Проверьте сначала короткий WAV. Этот пакет добавляет разделение, не генерацию песен.
